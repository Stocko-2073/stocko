C. Implementation of Contact Reduction

   To implement contact reduction, we use the concept of                      end
contact patches, which are sets of contacts that are proximal             end
and share a normal. We generate contact patches in 3 phases           end
(Algorithm 1). First, we Generate candidate contacts using
SDF collisions for a batch of triangles (size 1024). Second,
we Assign candidates to existing patches in the shape pair
based on normal similarity. Third, for unassigned candidates,
we FindDeepest (i.e., find the one with deepest penetration),
create a new patch, BinReduce (i.e., assign remaining candi-
dates to this patch based on normal similarity), and AddPatch
to our list of patches. We repeat until no candidates remain.
When performing AddPatch, we also check if a patch with a
similar normal exists. We either add both patches or replace the
existing patch, using a measure that maximizes patch surface
area, prioritizes contacts with high penetration depth, and
restricts the number of patches to N (where 128 ≤ N ≤ 256).
