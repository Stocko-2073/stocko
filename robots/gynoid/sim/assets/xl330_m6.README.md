# XL330 M6 parameters

`xl330_m6.json` is copied unchanged from `better-actuator-models==1.0.2`,
`bam/params/xl330/m6.json`. It matches the parameter file at Microduck's pinned
BAM commit `62bd8ce12154340be97e06f7f41a0ca8f116d967`.

Source: https://github.com/Rhoban/bam/blob/62bd8ce12154340be97e06f7f41a0ca8f116d967/bam/params/xl330/m6.json

BAM is provided under Apache-2.0: https://github.com/Rhoban/bam/blob/main/LICENSE

Supply voltage and firmware gain are set in the environment; the JSON contains
identified motor, friction and armature parameters. The testbench `q_offset`
parameter is not applied as a robot joint or encoder offset.
