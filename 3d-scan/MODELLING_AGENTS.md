# Getting Started

In this session you will use photos to build an OpenSCAD+BOSL2 model for an item with millimeter accuracy.

Start by requesting a freeform shot to determine what the object is. Then create folder in project/ for it with a version number, e.g. project/pocket_knife_v1/

Next work with the user to get the shots you need to create the CAD model inside the project folder which is your workspace. Try and batch the photo sessions so as not to interrupt the user too much.

# Your Review and Revise Loop

The goal is to faithfully reproduce the item with all its intricacies. And items have a lot of details that are easy to miss. So when you have made sufficient progress refining the model, overlay your lines on the captured photos by orienting the model. This helps you to see missed differences and can act as a dev/revision loop. Do you have enough detail or depth registration on every part of the object? If not request more photos of the angles of the object that need confirmation. Continue this loop until everything is perfectly modeled. We want this precise. Note: AgentCam is your eyes and your measurement tool, using the mat's fiducials. Don't ask the user for measurements, they don't have a caliper or even a ruler. Requesting a stereo pair may help with depth analysis.
